## Basic VPS 到底是什么线路？

这是很多人搞混的地方。Basic VPS 用的不是 CN2 GIA，而是普通线路，具体看你选哪个机房：

- 洛杉矶 DC2 (QNET)、DC8 (ZNET)、DC4 (MCOM)、弗吉尼亚弗里蒙特、纽约、新泽西等美国机房，走的是普通 163 骨干网方向，部分地区走 CN2 GT；
- 加拿大温哥华 CABC_1、荷兰阿姆斯特丹 EUNL_2 也是可选机房。

CN2 GT 和 CN2 GIA 的区别一句话说清：GT 是电信 CN2 网关转到普通骨干网，GIA 是全程走电信 CN2 独立线路，后者在晚高峰更稳定、延迟更低。Basic VPS 属于前者，所以国内访问速度谈不上惊艳，但也不会像某些廉价 VPS 那样绕路绕到没法用。

KiwiVM 控制面板里有一个 "Migrate to another DC" 功能，Basic VPS 可以在不同机房之间免费迁移，数据自动跟随。这意味着你可以先选一个机房试试，效果不满意再切到别的，不用重新买。这一点对新手比较友好。

## CPU 公平使用限制：官方条款怎么看

搬瓦工所有套餐（SLA 套餐除外）都执行 "Fair Share" 政策，核心规则是：允许短时间跑满 CPU，但一小时内平均占用不能超过套餐上限，超过后会自动降频（throttling），降回阈值后自动恢复，不会因此暂停 VPS。

Basic VPS 各档的 CPU 一小时平均上限如下（来源为官方服务条款）：

- **20GB 套餐**：50% of 1 Core
- **40GB 套餐**：75% of 1 Core
- **80GB 套餐**：100% of 1 Core
- **160GB 套餐**：100% of 1 Core + 50% of 第二核
- **320GB 套餐**：100% of 2 Cores
- **480GB 套餐**：100% of 3 Cores

注意这里写的是 "1 Core"，而套餐配置表里显示的是 2 核、3 核起步。也就是说，多核主要是给你应对瞬时并发，持续压力要看这条平均线。20GB 套餐的 50% 单核平均值，跑个博客、跑个轻量脚本没问题，拿来编译大项目或跑持续型计算任务就会撞线。

存储 I/O 也有类似规则：持续 4 小时以上超过 100 MiB/s 会被邮件警告，无视警告继续的话可能被临时暂停。这类限制在低价 VPS 里属于常见做法，不是搬瓦工独有。

## 常见问题

**Basic VPS 能用来建站吗？**

可以。20GB 套餐 1GB 内存跑 WordPress、静态博客、轻量 API 都没问题，1TB 月流量对应日均 33GB 左右的出口流量，对个人站点很充裕。但注意 CPU 限制（50% 单核平均），高并发场景会先撞到这个线。

**能不能跑 Docker？**

能。官方服务条款明确写着 Docker 是嵌套虚拟化禁令中的许可例外。但 QEMU 等完整嵌套虚拟化仍然被禁止。

**IP 被墙了怎么办？**

Basic VPS 可以通过 KiwiVM 面板的 IP 变更功能申请更换 IP。注意更换 IP 的费用不参与退款。选机房时可以考虑温哥华 CABC_1 或阿姆斯特丹 EUNL_2，这两处 IP 被墙概率相对低一些，但速度也会打折扣。

**流量用超了怎么办？**

Basic VPS 超出月流量后，搬瓦工的做法通常是限速而不是直接停机。具体超额策略以官方账单页面实际显示为准，这里不下定论。

**支持 Windows 吗？**

官方套餐说明里列出的系统都是 Linux 发行版。理论上可以通过手动 ISO 挂载尝试装 Windows，但这不在官方支持范围内，且 1GB 内存也跑不动，不建议在 Basic VPS 上折腾这个。
